# ADR 0021. Дизайн-рев'ю першого релізу (R-7)

- **Статус:** прийнято (вирішено)
- **Дата:** 2026-10-06
- **Закриває:** R-7 (`docs/architecture.md`, розділ 2)
- **Пов'язані рішення:** A-14, A-17, A-32, A-37 (`docs/architecture.md`, розділ 1); розділ 5.4; Додаток C; ADR 0016
- **Уточнено:** ADR 0022 (чотири питання розділу 14 інформаційної архітектури вирішено)

## Питання

R-7: фінальні кольори, шрифти, сітка й компоненти — умова масової реалізації інтерфейсу, після визначення екранів (R-6, ADR 0016).

## Рішення

Затверджено два документи дизайн-рев'ю в `docs/design/`:

- **`docs/design/design-system.md`** — дизайн-система: палітра й семантичні ролі з перевіреним контрастом WCAG AA, фінансова семантика кольору, типографіка (Segoe UI для інтерфейсу; Source Serif 4, вбудована, для заголовків екранів і головних сум), формат сум, шкала відступів, заокруглення 4 / 6 / 10, межі, один рівень тіні лише для діалогів, компоненти, позначки стану, повідомлення, піктограми Lucide.
- **`docs/design/ui-information-architecture.md`** — інформаційна архітектура: шість екранів ADR 0016 з ієрархією, навігація, форми, системні діалоги, майстер первинного налаштування, стани кожного екрана й перевірка узгодженості з ADR 0002–0020.

Основні рішення:
- Суми завжди графітові; тип операції передається піктограмою й підписом, а не кольором чи знаком.
- Архівність показується позначкою іншого виду, ніж статус життєвого циклу.
- Борги — в окремому блоці «Зобов'язання», без червоного кольору й знака мінус.
- Базовий мінімум — нейтральний орієнтир без вигляду ліміту.
- Минулі місяці — без кнопок дій, із банером «лише перегляд».
- Системна рамка вікна зберігається.

Попередні значення Додатка C `docs/architecture.md` замінено значеннями `docs/design/design-system.md`; зокрема `text-muted` затемнено до `#6B655C`, бо `#7A746A` не проходив AA.

## Межі

- Дизайн-рев'ю не змінює доменної моделі.
- Темна тема (D-1), англійський переклад (D-2) і графіки (D-9) не входять до першого релізу.
- Чотири питання доменної моделі, виявлені під час рев'ю, винесено в розділ «Потребує рішення» `docs/design/ui-information-architecture.md` із тимчасовою поведінкою інтерфейсу; вони не блокують реалізацію інтерфейсу.

## Наслідки

- R-7 закрито; відповідне рішення в `docs/architecture.md` — A-37. Масову реалізацію інтерфейсу можна починати за двома документами дизайн-рев'ю.
- Іконку застосунку (A-17) ще потрібно створити за цією палітрою на етапі реалізації.
- ADR 0001–0020 не змінюються.
