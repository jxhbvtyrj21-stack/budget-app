# ADR 0014. Метадані операцій архівованого накопичення (Q191)

- **Статус:** прийнято (вирішено)
- **Дата:** 2026-10-06
- **Фіксує:** рішення Q191
- **Уточнює:** ADR 0013, п. 4 (Q189)
- **Пов'язані рішення:** A-29, A-30 (`docs/architecture.md`, розділ 1); ADR 0011; ADR 0012; ADR 0013

## Контекст

ADR 0013 (Q189) заборонив редагувати й видаляти операції поточного календарного місяця, пов'язані з архівованим накопиченням, доки його не розархівовано. Водночас ADR 0012 дозволяє змінювати назву й опис поповнення поточного місяця без впливу на залишки (Q177) і редагувати назву й опис самого архівованого накопичення (Q184). ADR 0013 залишив відкритим питання, чи поширюється заборона Q189 на зміну лише назви чи опису таких операцій. Цей ADR фіксує рішення власниці продукту Q191.

## Рішення

### 1. Заборона Q189 стосується фінансових змін (Q191)

Заборона Q189 поширюється на зміни, які впливають на фінансовий стан операції, але **не блокує зміну назви чи опису**.

Для операції поточного календарного місяця, пов'язаної з архівованим накопиченням (звичайної витрати, джерелом якої є це накопичення, або поповнення цього накопичення):

**Заборонено до розархівування** (правило Q189 без змін):
- зміна суми;
- зміна джерела, набору джерел чи розподілу сум між джерелами;
- зміна накопичення-отримувача;
- видалення операції;
- будь-яка інша зміна, що впливає на фінансові залишки.

**Дозволено:**
- зміна назви;
- зміна опису.

Зміна назви чи опису:
- не змінює жодного залишку;
- не є фінансовою операцією;
- не відновлює архівований дохід;
- не змінює статусу накопичення;
- не розархівовує накопичення.

### 2. Принцип

Архівування блокує фінансові зміни, але не обов'язково блокує нефінансові метадані. Тому Q189 не означає повного режиму «лише перегляд» для кожного поля операції.

### 3. Минулі календарні місяці

Для операцій минулих календарних місяців діє окреме правило: уся операція доступна лише для перегляду, незалежно від того, чи є поле фінансовим, чи метаданими (ADR 0010, ADR 0011, ADR 0012).

## Узгодженість із попередніми рішеннями

| Правило | Зміст | Співвідношення з Q191 |
|---|---|---|
| Q177 (ADR 0012) | Назву й опис поповнення поточного місяця можна редагувати; це не змінює залишків | Узгоджено: діє й тоді, коли накопичення-отримувач архівоване |
| Q169 (ADR 0011) | Назву й опис звичайної витрати поточного місяця можна редагувати | Узгоджено: діє й тоді, коли джерело — архівоване накопичення |
| Q184 (ADR 0012) | Назву й опис накопичення, зокрема архівованого, можна редагувати | Узгоджено: той самий принцип для метаданих операцій |
| Q189 (ADR 0013) | Фінансові зміни операцій архівованого накопичення заблоковані до розархівування | Уточнено: заборона не охоплює назву й опис |
| Минулі місяці (ADR 0010, 0011, 0012) | Уся операція — лише перегляд | Без змін |

- **ADR 0009 (O-11)** не змінюється: архівований дохід не відновлюється.
- **ADR 0013** не змінюється за змістом, крім уточнення п. 4 (Q189); пункт «Потребує рішення» ADR 0013 вирішено цим ADR. До ADR 0013 додано примітку-посилання.
- Інші ADR не змінюються.

## Що цей ADR НЕ вирішує

- Інтерфейс редагування назви й опису — **O-7**.
- Структуру бази даних і конкретні доменні сутності.
