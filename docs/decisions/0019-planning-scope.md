# ADR 0019. Поняття «планування» в першому релізі (O-14)

- **Статус:** прийнято (вирішено)
- **Дата:** 2026-10-06
- **Закриває:** O-14 (`docs/architecture.md`, розділ 4)
- **Пов'язані рішення:** A-10, A-18, A-19, A-21, A-22, A-23, A-35 (`docs/architecture.md`, розділ 1); ADR 0002; ADR 0003; ADR 0005; ADR 0006; ADR 0007

## Питання

O-14: що саме охоплює «планування» з ADR 0002 (п. 2: «бюджетний період використовується для планування та аналізу»), крім введення базового мінімуму.

## Контекст

- **ADR 0002:** базовий мінімум — інформаційна сума для конкретного місяця; не план, не ліміт, не максимум.
- **ADR 0003, п. 13:** «розподілено = витрачено»; попереднього розподілу доходу на майбутні витрати немає. Розділ «Співвідношення з попередніми рішеннями» прямо зазначає, що слово «планування» в ADR 0002 не означає попереднього розподілу доходу.
- **ADR 0005:** поділу «базові / бажані» немає.
- **ADR 0006, ADR 0007:** фінансова ціль — це накопичення; окремої сутності цілі немає; цільова сума необов'язкова й не є лімітом; строків немає.

## Рішення

**Окремої функції планування в першому релізі немає.** Немає сутності «план», бюджетних лімітів за категоріями чи місяцями, системи «план — факт», планових витрат, попереднього розподілу доходу чи прогнозів.

У першому релізі «планування» означає лише наявні механізми:

1. **Базовий мінімум місяця** — орієнтир, який користувач вводить для календарного місяця (ADR 0002); він порівнюється з фактичними витратами лише інформаційно (ADR 0020).
2. **Накопичення з необов'язковою цільовою сумою** — відкладання коштів на конкретний майбутній результат із показом прогресу (ADR 0006, ADR 0007).
3. **Загальна доступна сума й окремі залишки джерел** — інформація для рішень користувача про майбутні витрати (ADR 0003).

Слово «планування» в ADR 0002, п. 2 тлумачиться саме так.

## Наслідки

- O-14 закрито; відповідне рішення в `docs/architecture.md` — A-35.
- Нових сутностей, полів чи операцій не вводиться.
- Аналіз періоду (ADR 0020) не містить порівняння «план — факт», крім інформаційного порівняння з базовим мінімумом.
- ADR 0001–0014 не змінюються.
